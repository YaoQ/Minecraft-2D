# 世界高度 262 设计稿

## 目标

- 将世界高度从 `180` 调整为 `262` 格。
- 新增的高度用于“增加上方天空”，而不是增加地下深度或底部虚空。

## 现状

- `WORLD_HEIGHT = 180`
- 地表高度（`surfaceY`）在较小范围内波动，并基于该值生成地形/洞穴/矿物/水/岩浆等。
- 直接把 `WORLD_HEIGHT` 变大只会让底部出现更多 `VOID`，天空高度并不会增加。

## 方案（已确认）

### 1) 垂直整体下移

- 设置：
  - `WORLD_HEIGHT = 262`
  - `SKY_OFFSET = 262 - 180 = 82`
- 将“地表/海平面/基岩层”等整体下移 `SKY_OFFSET`：
  - `surfaceY += SKY_OFFSET`
  - `seaLevel += SKY_OFFSET`
  - `LAYER_OFFSET_Y += SKY_OFFSET`（用于保持基岩层深度相对地表不变）
- 效果：
  - 顶部空气层明显变厚（天空更高）
  - 地下深度与原来接近（玩法节奏不突变）

### 2) 出生点按地表计算

- 将玩家出生点从“固定常量高度”改为“按地表高度计算”：
  - 找到一个陆地区块的 `spawnTileX`
  - `spawnY = (surfaceHeights[spawnTileX] - 2) * TILE_SIZE`
- 目的：
  - 避免出生在海里/方块内/高空坠落
  - 与世界整体下移后的新地表保持一致

## 验收标准

- 世界高度为 262（数组维度与渲染/碰撞/生成逻辑均正常）
- 天空高度明显增加（玩家出生点上方空气层更多）
- 不出现出生即卡方块/坠落致死
- 世界生成（矿物、洞穴、树、流体）保持可玩且无明显异常
